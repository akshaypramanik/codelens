# CodeLens for Java

Write Java and step through it. Variables, arrays, stacks, queues, lists, trees, maps and 2D grids are drawn live. Runs fully in your browser.

### Java program

What Java is supported?

Single-file programs with `main`, static methods and recursion, `int/double/boolean/String`, arrays (1D/2D), loops, `if/switch`, user classes (use `this.field` inside methods), `ArrayList, LinkedList, Stack, Queue, ArrayDeque, PriorityQueue, HashMap, HashSet, StringBuilder, Arrays, Collections, Math`. Not supported: char arithmetic (`c - 'a'`), interfaces/lambdas/streams, multithreading, Scanner input. Limit: 3000 steps.
